## Overview

**Remember Me** is a relationship-driven gifting and wishlist platform. Phase 1 MVP helps users remember important dates, save gift ideas, plan events, and create **"Thinking of You" gift-card drafts** — with honest scope boundaries (no payments or delivery in Phase 1).

**Tagline:** *Never miss a moment that matters.*

---

## Problem

People forget important dates and lose gift ideas across notes apps, messages, and memory. Remember Me centralizes **relationship context**, reminders, wishlists, and draft gifting flows in one calm MVP.

## Stack

Next.js 16 · TypeScript · Tailwind v4 · Supabase Auth · Demo mode (localStorage)

---

## Key Features (Phase 1)

- Public landing with honest MVP messaging  
- Email/password auth (Supabase) when configured  
- Dashboard, wishlist CRUD, reminders, events with countdown  
- Thinking of You **draft** flow (no real delivery)  
- **Demo mode** — full walkthrough without Supabase via `/demo`  

### Intentionally not included (Phase 1)

Real gift-card delivery, payments, automated imports, notifications, group contributions — documented honestly in README and UI copy.

---

## Technical Decisions

- **Demo mode first-class** — cookie + localStorage store for stakeholder demos  
- **Design tokens** — Figma-aligned tokens in `lib/design-tokens.ts`  
- **Phase disclaimers in UI** — avoids overpromising in client/stakeholder demos
