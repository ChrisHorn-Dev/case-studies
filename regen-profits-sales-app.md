## Overview

Mobile-first **Progressive Web App (PWA)** for sales reps and admins: daily sales logging, leaderboards, competitions, funnel views, and an admin command center. Built with Next.js 16, Supabase Auth/Postgres/RLS, and Tailwind v4.

---

## Problem

Distributed sales teams need **fast mobile access** to log activity, see progress, and stay accountable — without a native app store release cycle. Admins need visibility into rep performance and operational oversight from the same system.
